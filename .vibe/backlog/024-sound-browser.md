# Sound browser with playback

## Description
character-editor lists and plays a character's sounds (item 017) via snd. The viewer, whose role is to inspect everything about a character, should offer the same read-only browsing and preview.

## Acceptance Criteria
- [ ] Sounds listed by group/number with playback
- [ ] Undecodable sounds listed with the reason
- [ ] Reuses the same snd WASM build as the editor
