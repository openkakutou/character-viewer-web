# Module: i18n
**Role:** This app's own localization setup (backlog item 018, roadmap decision `023-localization-approach-for-web-ui.md`), wiring `@openkakutou/web-ui-kit`'s shared i18next integration layer under this app's own namespace (`"character-viewer-web"`) and its own `localStorage` key (`"character-viewer-web-locale"`, not `web-ui-kit`'s shared default — every OpenKakutou app deploys as its own GitHub Pages project site on the same origin, so sharing the default key would leak one app's language choice into every other one). `t(key, defaultValue, vars?)` mirrors `web-ui-kit`'s own `t()` contract exactly: it returns the interpolated `defaultValue` verbatim whenever `initAppI18n` hasn't resolved yet in this page (e.g. every existing test, which never bootstraps i18n), and otherwise delegates to the active instance under this app's namespace — every call site's `defaultValue` matches its `en.json` entry character-for-character, so a render is identical whichever path it takes. `en.json`/`fr.json` are this app's own message catalogs (English source/default, French the second supported locale per the roadmap decision). `initAppI18n` is only ever called once, from `modules/app.md`'s real `mount()` bootstrap, awaited before the first render — never from `renderApp` itself.
**Files:** `src/i18n/i18n.ts`, `src/i18n/en.json`, `src/i18n/fr.json`
**Exports:** `initAppI18n(): Promise<I18nInstance>`, `getI18n(): I18nInstance | undefined`, `onLocaleChange(callback: () => void): () => void`, `t(key: string, defaultValue: string, vars?: Record<string, string>): string`, `NAMESPACE: string`, `I18nInstance` (type)
**Depends on:** `@openkakutou/web-ui-kit` (external — `initI18n`, `getI18n`, `onLocaleChange`, `t`, `<wuik-locale-switcher>`; typed locally via `src/types/web-ui-kit.d.ts`, an ambient `declare module` covering only what this app imports by name, since the installed package ships no `.d.ts` of its own)
