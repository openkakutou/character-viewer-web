# Module: input
**Role:** The character file input: folder selection only (item 015, replacing item 003's per-kind picker/drop zone outright — see `.vibe/decisions/017-folder-only-input-def-files-parse-and-ported-resolution.md`). Gathers a picked/dropped folder's full file listing, picks its `.def` entry point (auto if exactly one, otherwise prompts the user among every candidate found), learns which `.air`/`.sff`/`.cns` filenames it references via a narrow local `[Files]`-section read, resolves each by basename against the folder listing (exact case first, case-insensitive fallback second, more than one match reported as ambiguous rather than guessed), then loads the character through the `wasm` bridge. On success, also threads the raw `.sff` bytes it already read back out (`CharacterInputResult.sffBytes`, `onLoaded`'s second argument) — not re-read — so a caller can later decode a specific sprite's pixels on demand (item 005, `.vibe/decisions/006`). Also renders the folder-picker + drag-and-drop UI, including the multi-`.def` candidate picker (a native `<fieldset>`/`<legend>` radio group with a confirm button disabled until a choice is made).
