# Module: shell
**Role:** The launch screen → persistent workspace transition (backlog item 020). `launch-screen.ts` renders a full-frame wrapper around `input`'s existing file input view — no toolbar/sidebar chrome, since nothing else exists to navigate to before a character loads. Once its `onLoaded` callback fires, `workspace-shell.ts` replaces the launch screen entirely with a persistent `wuik-app-shell`: a toolbar (app title/version + the character's name) and a vertical `wuik-tabs` unit (tab-list strip + one `wuik-tab-panel` per section — Characteristics, Palette, Sprites, Animation from `viewer`, In-game preview from `game-mode` (item 008)) composed and laid out as one piece via CSS Grid on the tabs host element, since `wuik-app-shell`'s own sidebar/main slots can't be split across the component (`.vibe/decisions/011`). Every section's render function is called exactly once and stays mounted for the life of the shell — `wuik-tabs` only toggles a panel's `hidden` attribute on switch, never destroying/re-rendering it, which is what lets each section keep its own selection, expanded groups, and playback position across switches with no extra plumbing. A single `MutationObserver` watches every panel's `hidden` attribute and reacts to it flipping: pausing the animation player and, separately, the in-game preview's own trigger playback (each via its own `pause()` handle method) when their panel becomes hidden, and moving focus to the newly visible panel's own heading (`h1`–`h3`) — the only two behaviors `wuik-tabs` itself has no event for. Characteristics is created first and never receives a `hidden` mutation of its own on initial mount (nothing hid it), so its first-mount focus move is done explicitly rather than through the observer.

**Exports:** `renderLaunchScreen(root: HTMLElement, options: LaunchScreenOptions): void`, `LaunchScreenOptions`, `renderWorkspaceShell(root: HTMLElement, version: string, character: CharacterData, sffBytes: Uint8Array, options?: WorkspaceShellOptions): void`, `WorkspaceShellOptions`
