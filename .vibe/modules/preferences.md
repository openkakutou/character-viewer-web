# Module: preferences
**Role:** A single session-scoped app setting, "beginner mode" (backlog item 022), off by default and never persisted to `localStorage` — the acceptance criteria only require it to survive the rest of the session (including a character switch, item 021), not a page reload, mirroring how the rest of this app's state already resets on reload. `preferences.ts` holds the flag itself behind a plain subscribe/notify API (`onBeginnerModeChange`), the same shape `modules/i18n.md`'s own `onLocaleChange` already established, and notifies only when the value actually changes. `info-tooltip.ts` builds the reusable info-icon + tooltip-bubble widget `modules/viewer.md`'s four screens each mount one of, next to a MUGEN/Ikemen term: the icon and its bubble are always real DOM, present regardless of beginner mode's own state — only the outer wrapper's `hidden` attribute toggles — so the trigger's `aria-describedby` association never dangles and a screen reader always has something to announce once the icon receives focus. The bubble is positioned with `position: fixed`, computed via `computeTooltipPosition` (a pure function, independently unit-tested with plain rect/size inputs) from the trigger's own `getBoundingClientRect()` at reveal time, so it can never be clipped by a section's own internal `overflow-y: auto` scrollbar the way an `absolute`-positioned bubble nested in that scroll container would be. The bubble reveals on hover, keyboard focus, and click (the last one specifically so a touch tap — which has no hover — still opens it), and dismisses on Escape without moving focus away from the trigger. `beginner-mode-toggle.ts` renders the actual "Beginner mode" checkbox+label+hint mounted once inside `modules/shell.md`'s Preferences dialog — reusing the plain `<input type="checkbox">` + `<label>` pattern already established by the animation player's own "Loop"/"Show collision boxes" toggles, since no dedicated switch/toggle component exists yet in `@openkakutou/web-ui-kit`. See `.vibe/decisions/022-beginner-mode-tooltip-widget-and-placement.md`.
