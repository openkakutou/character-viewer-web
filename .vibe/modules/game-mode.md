# Module: game-mode
**Role:** The in-game preview mode (item 008): a screen hosted as a fifth section of `modules/shell.md`'s workspace, listing every one of the loaded character's animations as its own trigger button rather than `viewer`'s Animation section's dropdown/step/manual-loop/collision-overlay debug UI. Clicking a button plays that animation immediately, looping continuously by default (no opt-in checkbox, unlike the debug player) so it reads as "how this behaves in a match" rather than a frame inspector — see `.vibe/decisions/012-in-game-preview-trigger-buttons-loop-and-stop-toggle.md`. Clicking a different animation's button while one is playing replaces it cleanly (its own timer chain and any in-flight decode are cancelled first, same selection-token-guarded pattern as the sprite browser/animation player); clicking the *currently playing* animation's own button again stops it in place instead of restarting it or being a no-op — the only "stop" affordance this section has, since a separate pause control would duplicate the debug Animation tab it deliberately avoids being. Reuses `viewer/animation-player.ts`'s already-exported pure timing helpers (`effectiveTickDuration`, `isBlankFrame`, `computeNextFrameIndex`) and `viewer/sprite-browser.ts`'s decode/draw helpers (`computeScaleToFit`, `defaultDrawPixels`) rather than embedding the whole debug player component. Returns the same small `{ pause() }` handle shape as the animation player so `shell`'s workspace can auto-pause it (and clear its active button's pressed state) when the user navigates away from its section, per item 020's existing convention.
**Files:** `src/game-mode/animation-triggers.ts`
**Exports:** `renderAnimationTriggers(root: HTMLElement, character: CharacterData | null, sffBytes: Uint8Array | null, options?: AnimationTriggersOptions): AnimationTriggersHandle`, `AnimationTriggersHandle` (`pause`), `AnimationTriggersOptions`
**Depends on:** `modules/wasm.md` (`CharacterData`, `resolveSpritePixels`, `SpritePixelResult`, `WasmBridgeOptions`, `Frame`, `Animation`), `modules/viewer.md` (`effectiveTickDuration`, `isBlankFrame`, `computeNextFrameIndex`, `MS_PER_TICK` from `animation-player.ts`; `computeScaleToFit`, `defaultDrawPixels` from `sprite-browser.ts`)
